# Support

Read the [documentation](docs/index.md) and use the
[issue tracker](https://github.com/altophp/favicon/issues) for questions or bugs.

Include PHP and package versions, source format and dimensions, CLI command or
PHP options, adapter and executable versions, and the complete error or
created/skipped report. State whether the failure is rasterization, writing,
or browser URL integration. Include PSR logger output when an adapter fails.

Share a small redistributable SVG or PNG with private content removed. For
feature requests, describe the target platform and generated files you need.
